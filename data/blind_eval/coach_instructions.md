# 教练盲评须知

感谢您协助完成本研究的外部效度验证！

## 操作步骤

1. 用浏览器打开同目录下的 `coach_rating.html`（双击即可，无需网络）。
2. 页面共 43 段视频，逐个观看后在对应输入框填写：
   - **评分（0-100）**：蹬腿技术正确性打分。
   - **备注**（可选）：任何观察或疑虑。
3. 全部填完后，点击页面底部「导出评分 CSV」按钮，浏览器会下载
   `filled_coach_sheet.csv`。
4. 将 `filled_coach_sheet.csv` 回传给研究者即可，无需回传其它文件。

## 评分说明（rubric）



  - <b>90-100</b> 技术优秀，接近竞技水平 / Excellent, near-competitive
      （对称、外翻蹬水充分、无明显瑕疵 / symmetric, full outward whip, no visible flaws）
  - <b>75-89</b> 良好，仅轻微问题 / Good, only minor issues
  - <b>60-74</b> 基本正确但有明显可纠正问题 / Basically correct but with
      clear, fixable issues
  - <b>40-59</b> 多处技术错误 / Multiple technical errors
      （明显不对称/剪式腿/时序紊乱 / visible asymmetry, scissor kick, timing disorder）
  - <b>0-39</b> 严重错误或几乎不成形 / Severe errors or barely recognizable form



## 重要提醒

- 请**独立打分**，评分锚点仅供参考，可按您自身专业标准判断。
- 评的是**蹬腿技术正确性**，不是速度、名次或整体印象。
- **请勿查阅任何系统评分**——本次评估的目的正是检验系统评分与专家判断的
  一致性，若参考了系统分会使结果失去意义。
- 相对排序（谁比谁更好）比绝对分值更重要，请尽量保持评分内部一致。
